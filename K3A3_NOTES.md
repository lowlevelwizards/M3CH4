# M3CH4 0.0.1k.3a.3 — Engineered Yardwalker + Measured Chassis Guides

**Complete repository baseline:** `lowlevelwizards/M3CH4` `main` at `f77556a898e3176f5f05d42c22997132e796587c` (k.3a.2 Equipment Fit Lab already installed). This archive is ONLY new or modified files plus missing earlier regression test files. It is **not a complete game**, and it intentionally does not restore the deleted `K2_NOTES.md`. Overlay its unzipped contents on the **complete existing repository**; never merge an otherwise-empty patch-only Git branch over the entire game.

## What changed

- `mobilityDefinitions.js` — NEW pure, precise *rest-pose* engineering data for **only** the existing `legs-yard` component, including one canonical U1 pad, transverse carriage, mirrored hip/knee/ankle/foot anchors, real lateral stabilizer receiver faces, existing source-envelope checks and one single functional paired-mobility input. The gameplay catalogue remains the sole source of original mass, size, power and handling.
- `mobilityVisualKit.js` — NEW shared simple industrial mechanical geometry: named load-bearing beams, exposed cylindrical bearings, physical actuator barrels/rods, structural blocks and restrained common materials. No decorative micro-details, new gait solver or separate independent owned leg objects.
- `yardwalkerVisual.js` — NEW actual low-poly **Yardwalker** model made from the shared kit: central pad, short support pedestal, load-bearing crossbeam, real left/right hip joints, connected upper links, knee pivots, lower links, ankle pivots, two broad industrial feet, one fixed visibly connected actuator and one upper cover per leg. Named parented hip→knee→ankle→foot groups are provided for a later animation pass. Exact original fixture envelope and top mating point retained. Also renders TWO fixed detachable preview guide brackets generated from measured chassis contacts, rather than floating/socket dots.
- `mobilityGuide.js` — NEW pure measurement of the frame-specific bracket paths: ACTUAL frame hip-boss outward surface to ACTUAL Yardwalker saddle-side fixed receiver surface, using the verified centralized U1 placement, with max-length validation. Approximate lengths for each LEFT/RIGHT bracket: Hub **0.439 m**, Twin-Rail **0.499 m**, Tub **0.489 m**. Both sides of each are matched. No silent moving/lengthening of leg parts or chassis socket coordinates.
- `chassisFitVisuals.js` — Existing standard envelopes still back all four fixtures; by default `legs-yard` uses the engineered visual instead of the old generic block. Old schematic remains selectable for an honest side-by-side comparison. Cab, generator and gun are unchanged.
- `chassisFitValidation.js` — Third optional *preview-only* analysis argument adds provisional measured-guide review logic. When guide hardware is absent, the previous exact unbridged gap warnings are preserved; when guides are shown, the bridges exist as geometry, but are still marked REVIEW (no rated strength/mass or production hardware). All original fixture alignment/clearance flags, including the Ladder gun/hip envelope warning, remain.
- `chassisFitPreview.js`, `chassisPreview.js`, `chassis-preview.html` — In assembled mode choose **ENGINEERED** or **OLD FIT BLOCK**; toggle the frame-side brackets; hide individual components; keep the existing three bare frames, camera presets, touch controls, source dimensions and inspectable review warnings. Nested changed imports and page JS revision are cache-busted with `k3a3`. Bare mode and the approved bare chassis geometry remain unchanged.
- `tests/` — Includes the older k.1/k.2/k.3a/k.3a.1/k.3a.2 test sources missing on GitHub `main`, plus updated preview tests and **11 new Yardwalker/guide/renderer simulation tests**. Preserve this folder when uploading the overlay.

## Scope protection

**Only Yardwalker is reconstructed.** Kestrel and Hauler H2 remain the earlier game parts; the Kestrel/Hauler art and H2 conversion adapter are intentionally not reworked here. The other three equipment test fixtures remain provisional; the eight-frame program remains scoped to the three approved chassis. The new frame-side guide links are design **studies**, NOT independently owned adapters and NOT part of total vehicle mass, save serialization, collision damage or future physics until balanced and modeled as real components. They cannot make an otherwise incompatible game build deployable.

**No changes to** live `index.html`, `main.js`, `scene.js`, `components.js`, `assemblyGraph.js`, `persistence.js`, live garage, combat, locomotion, original serials or user saves. The game still displays its preexisting Yardwalker art until a separately tested live renderer integration.

## Install and inspect on iPhone

1. Save the ZIP locally, extract it, add/overwrite its files in your **complete** `M3CH4` GitHub repository root next to `index.html`, and commit the real files plus `tests/`. Leave every other existing game file untouched. Do not upload only the ZIP or replace the branch with a patch-only tree.
2. Open `https://lowlevelwizards.github.io/M3CH4/chassis-preview.html` and hard-refresh if old JavaScript is cached. Select any of the three frames, tap **ASSEMBLED**, select **ENGINEERED** under Yardwalker study, and leave "Show 2 measured...guide brackets" checked. Rotate to the right/side view to inspect each bracket.
3. Disable the brackets: the old physical gaps must be visible and reported. Toggle **OLD FIT BLOCK** to compare the prior generic Yardwalker silhouette; the underlying four equipment placements and mass diagnostics must NOT change. Toggle the legs off: the preview brackets hide with them, without unequipping the part. Check the live arena and current garage/save afterwards.
